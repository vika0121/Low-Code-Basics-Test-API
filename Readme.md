# Low Code Basics - Test API

Test repository for the **Low Code Basics** YouTube channel.
Use it to practice calling the GitHub REST API from Appian.

## Try it

No token or login needed. This repo is public.

- Repo details: `GET https://api.github.com/repos/vika0121/Low-Code-Basics-Test-API`
- Languages: `GET https://api.github.com/repos/vika0121/Low-Code-Basics-Test-API/languages`
- Issues: `GET https://api.github.com/repos/vika0121/Low-Code-Basics-Test-API/issues`

## Notes

- Unauthenticated requests are limited to 60 per hour per IP address.
- To try POST (creating an issue), create your own repo and token. Don't use this one.
